# Changelog

## 0.1.0 — 2026-03-14

Initial release.

### Features

- **Bookmark management** — Organize bookmarks into color-coded groups with drag-and-drop reordering
- **Tab tracking** — See which bookmarks are open, with green dot indicators and active tab highlighting
- **Floating tabs** — Tabs opened from bookmarks stay grouped even without being bookmarked
- **Side panel** — Full bookmark manager accessible as a side panel or standalone window
- **Quick search popup** — Fuzzy search across bookmarks and tabs (Alt+J)
- **New tab page** — Optional new tab replacement with bookmark grid and web search
- **Sub-groups** — One level of group nesting for hierarchical organization
- **Chrome tab group sync** — Sync Tab Junkie groups to Chrome's native tab groups
- **Multi-select** — Shift/Ctrl+click, Ctrl+A for bulk operations (move, close, remove)
- **Context menus** — Right-click actions on bookmarks, groups, and selections
- **Import/export** — HTML (Netscape format) and JSON backup/restore
- **Theme selector** — 12 IDE color themes (Monokai, Dracula, One Dark, Nord, Solarized, Gruvbox, Tokyo Night, GitHub Light, and more)
- **Keyboard shortcuts** — Alt+J (popup), Alt+Shift+J (window), arrow keys, Enter, Escape
